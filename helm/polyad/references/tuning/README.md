Overlay for any architecture. Cadences pause AFTER a pass, not on a fixed clock.

Apply this overlay with the chart defaults; review its settings before deployment.

```sh
helm template polyad helm/polyad --values helm/polyad/references/tuning/values.yaml
```

## Parameters

### Configuration

| Name                                                               | Description                                                                                                                                                                                                                                                                                                       | Value            |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `operator.writeQueue.plannerParallelism`                           | **Type: integer.** Maximum mutation callbacks per approved planner batch. One keeps batches serial; callers may lower this ceiling only. Parallel transport also needs maxInFlight slots and sufficient maxInFlight + maxPending admission capacity per adapter. Dependency and shared-budget checks still apply. | `1` |
| `operator.writeQueue.maxInFlight`                                  | **Type: integer.** Concurrent writer slots per API adapter. One preserves serial transport; higher values admit only independent writes approved by the same refreshed mutation batch. Unknown effects remain ordered.                                                                                            | `1` |
| `operator.writeQueue.validationWorkers`                            | **Type: integer.** Concurrent candidate validations per API adapter, shared by the background producer and dispatchers. Increasing this consumes Kubernetes read capacity.                                                                                                                                        | `1` |
| `operator.writeQueue.reconciliationWorkers`                        | **Type: integer.** Concurrent local reconciliation attempts and remote deliveries per cluster. Same-key follow-ups and graph-family leases remain serialized; separate families can prepare decisions together.                                                                                                   | `1` |
| `operator.writeQueue.reconciliationCooldownSeconds`                | **Type: number.** Shared cooldown window in seconds; zero disables additional pulse pacing. Refused work retries from fresh state.                                                                                                                                                                                | `0` |
| `operator.writeQueue.reconciliationBurst`                          | **Type: integer.** Maximum new pulses admitted in one cooldown window; duplicate retries do not extend the window.                                                                                                                                                                                                | `1` |
| `operator.writeQueue.maxPending`                                   | **Type: integer.** Extra admitted writes beyond maxInFlight per adapter. One favors fresh decisions; zero removes extra capacity. Unproven independence can still cause admitted items to wait. Overflow requires fresh reconciliation.                                                                           | `1` |
| `operator.writeQueue.validationIntervalSeconds`                    | **Type: number.** Maximum pause between validation passes; watch notifications wake the producer sooner. Must not exceed validationWindowSeconds.                                                                                                                                                                 | `1` |
| `operator.writeQueue.validationWindowSeconds`                      | **Type: number.** Maximum reusable validation age measured from its start. Shorter windows add reads; longer windows tolerate more unobserved external drift. Events and relevant writes invalidate receipts immediately.                                                                                         | `5` |
| `operator.writeQueue.validationBurst`                              | **Type: integer.** Maximum candidates validated per background pass; spare window time advances through later queued items without adding mutation concurrency.                                                                                                                                                   | `8` |
| `operator.cheeger.maxVertices`                                     | **Type: integer.** Maximum vertices per boundary; defaults to 20. Larger connected boundaries also need increased cut and time budgets.                                                                                                                                                                           | `20` |
| `operator.cheeger.maxCuts`                                         | **Type: integer.** Maximum distinct cuts per calculation; 524287 covers 20 vertices. Budget exhaustion blocks constrained actions.                                                                                                                                                                                | `524287` |
| `operator.cheeger.timeoutSeconds`                                  | **Type: number.** Cooperative runtime ceiling per calculation, checked between batches. Incomplete search is never an exact constant.                                                                                                                                                                             | `5` |
| `operator.cheeger.reduction.enabled`                               | **Type: boolean.** Permit policy authors to request the reduction tiers. False preserves exact-only behavior.                                                                                                                                                                                                     | `false` |

| `operator.cheeger.reduction.components`                            | **Type: integer.** Maximum nontrivial Laplacian eigenvectors a policy may retain.                                                                                                                                                                                                                                 | `4` |
| `operator.cheeger.reduction.supernodes`                            | **Type: integer.** Maximum quotient vertices a policy may search.                                                                                                                                                                                                                                                 | `8` |
| `operator.cheeger.reduction.cache`                                 | **Type: boolean.** Permit cached partition reuse. Measurements are never reused; partitions are rescored on current edges.                                                                                                                                                                                        | `true` |
| `operator.cheeger.reduction.cacheEntries`                          | **Type: integer.** Maximum process-local cached partitions.                                                                                                                                                                                                                                                       | `128` |
| `operator.cheeger.reduction.maxEdgeChurn`                          | **Type: number.** Maximum changed-edge fraction for cached partition reuse.                                                                                                                                                                                                                                       | `0.1` |
